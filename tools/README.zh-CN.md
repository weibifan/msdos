# DOS 工具合集

用于复古计算的实用 DOS 工具。

| 文件 | 说明 |
|------|------|
| ARJ.EXE | ARJ v2.50 文件归档器，高压缩比，支持多卷，90 年代广泛使用 |
| pkzip250.exe | PKZIP v2.50 文件归档器，行业标准 ZIP 压缩 |
| pct9.zip | PC Tools 9.0 综合 DOS 工具套件，包含文件管理器、磁盘编辑器、恢复工具等 |
| sea13.zip | Sea v1.3 快速 VESA 图像查看器/转换器，支持多种图像和动画格式 |
| TT/ | Typing Tutor IV 打字教学程序 |
