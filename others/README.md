# Other Utilities

Additional DOS/Windows tools for disk imaging and ISO management.

| File | Description |
|------|-------------|
| `UltraISO-9.7.6.3860-CN.zip` | UltraISO v9.7.6.3860 (Chinese version) — CD/DVD image file editor and creator. Handles ISO, BIN, NRG, and other image formats. |
| `WinImage11-cn.zip` | WinImage v11 (Chinese version) — disk image utility for creating, reading, and editing floppy and hard disk images. |
