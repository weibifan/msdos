# VMware Workstation 5.5 中的 MS-DOS 6.22

预配置的 VMware 虚拟机，已安装 MS-DOS 6.22。

## 文件

- **ms-dos-vmware-5.5.zip** — 压缩的 VM 包，包含：
  - 已安装 MS-DOS 6.22 的虚拟硬盘
  - VMware 配置文件 (.vmx)
  - 针对 MS-DOS 优化的 BIOS 和 VM 设置

## 快速开始

1. 解压 ms-dos-vmware-5.5.zip
2. 使用 **VMware Workstation 5.x** 或更高版本打开 .vmx 文件
3. 启动虚拟机

## VM 规格

| 组件 | 详情 |
|------|------|
| CPU | 1 vCPU |
| 内存 | 64 MB |
| 存储 | 200 MB IDE 磁盘 |
| 网络 | 无 |
| 声卡 | PC 扬声器 |
| 显卡 | 标准 VGA |
| 软驱 | 1.44 MB 软驱 |

## 备注

- 兼容 VMware Workstation 5.x、6.x 及更高版本
- 也可以导入 VirtualBox（可能需要调整配置）
