# 经典 Windows 合集（1.x — 3.x）

早期 Microsoft Windows 安装盘及中文版本。

## 文件列表

| 文件 | 说明 |
|------|------|
| `windows-1.0-setup-disk.zip` | Microsoft Windows 1.0（1985）— 微软首个 GUI 操作系统 |
| `chinese-windows-3.2-setup-disk.zip` | PWIN 3.2 — 中文版 Windows 3.2 |

## 说明

- Windows 1.0 需要 MS-DOS 和 CGA/EGA/VGA 显卡适配器
- PWIN 3.2 是微软首个官方中文版 Windows，于 1994 年发布
- 这些为历史软件，仅供教育和存档用途
