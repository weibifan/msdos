# Retro Windows Collection (1.x — 3.x)

Early Microsoft Windows installation disks and Chinese localized versions.

## Files

| File | Description |
|------|-------------|
| `windows-1.0-setup-disk.zip` | Microsoft Windows 1.0 (1985) — the first GUI OS from Microsoft |
| `chinese-windows-3.2-setup-disk.zip` | PWIN 3.2 — Chinese localized Windows 3.2 |

## Notes

- Windows 1.0 required MS-DOS and a CGA/EGA/VGA graphics adapter
- PWIN 3.2 was the first official Chinese version of Windows, released in 1994
- These are historical software for educational and archival purposes only
