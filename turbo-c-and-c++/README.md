# C and C++ Development Tools

Borland Turbo C and Turbo C++ development environments for MS-DOS, packaged as complete disk archives.

| File | Description |
|------|-------------|
| `Turbo C 2.01 (5.25-360k).zip` | Turbo C 2.01 — Borland's classic MS-DOS C compiler. Includes 6 disk images (360 KB each): Install/Help, IDE, Command Line/Utilities, Libraries, Header Files, Examples/BGI/Misc. |
| `Turbo C++ 3.0.zip` | Turbo C++ 3.0 — Borland's object-oriented C++ IDE for MS-DOS. Complete package with compiler, linker, libraries, and headers. |
