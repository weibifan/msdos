# DOS 模拟/虚拟化软件对比

> 本文档对比主流可用于运行 MS-DOS 的模拟器与虚拟机软件，涵盖原理、适用场景、优缺点。

---

## 1. DOSBox

| 项目 | 说明 |
|------|------|
| **官网** | https://www.dosbox.com |
| **类型** | 模拟器（高精度 DOS 环境模拟） |
| **开源** | GPL-2.0 |
| **平台** | Windows / macOS / Linux |

### 原理

DOSBox 并非完整 x86 模拟器，而是**高层模拟（High-Level Emulation）** DOS 环境——它模拟的是 DOS API 和 BIOS 中断行为，而非底层 x86 硬件。它内置了 DOS 内核（无需安装 MS-DOS），直接将 DOS 程序调用映射到宿主系统。

### 优点

- **零配置运行 DOS 游戏**——内置 DOS 内核，无需安装操作系统
- **跨平台**——Windows/macOS/Linux 均可运行
- **性能优秀**——动态重编译，在现代硬件上运行 DOS 程序绰绰有余
- **广泛兼容**——GOG 等平台使用 DOSBox 打包经典 DOS 游戏
- **自动挂载**——可直接映射宿主机目录为 DOS 盘符
- **动态调速**——可通过 `cycles=` 动态调整 CPU 速度，适配依赖时钟的老游戏

### 缺点

- **不是完整 x86 模拟**——无法运行需要特定硬件特性的程序（如 Windows 95/98）
- **硬件模拟有限**——仅模拟 Sound Blaster、VGA/SVGA、PC 扬声器等常用硬件
- **精度不足**——对依赖硬件时序的老软件兼容性不如 86Box
- **不支持中文 DOS 系统**——无法直接运行 UCDOS、CCED 等中文环境
- **并行端口模拟受限**——主要用于 Covox/DSS 声卡而非打印机
- **开发已停滞**——原版 DOSBox 自 2019 年后更新缓慢

### 适合场景

- DOS 游戏玩家（90% 的 DOS 游戏可完美运行）
- 快速体验 DOS 软件
- GOG 游戏分发

## 2. DOSBox-X

| 项目 | 说明 |
|------|------|
| **官网** | https://dosbox-x.com |
| **类型** | 模拟器（DOSBox 分支，精度更高） |
| **开源** | GPL-2.0 |
| **平台** | Windows / macOS / Linux |

### 原理

DOSBox-X 是 DOSBox 的功能增强分支。与 DOSBox 相比，它：

- 支持**挂载真实 MS-DOS/FreeDOS 系统**（在 DOSBox-X 中引导真正的 DOS）
- 模拟更多硬件（Voodoo、3dfx、更好的 SVGA 支持）
- 更精细的配置选项

### 优点

- **支持安装真实 DOS**——可以引导 MS-DOS 6.22、FreeDOS 等
- **Windows 9x 支持**——可运行 Windows 95/98（实验性）
- **3dfx Voodoo 模拟**——支持 Glide 游戏
- **中文支持较好**——对中文 DOS 软件兼容度高于 DOSBox
- **持续活跃开发**——社区更新频繁
- **更多视频模式**——VESA 2.0、S3 Trio64 等
- **打印机和其他外设模拟**

### 缺点

- **性能略低于 DOSBox**——更精确的模拟带来额外的 CPU 开销
- **配置更复杂**——选项过多，对新手不太友好
- **并非完整 x86 模拟**——尽管能运行 Windows 9x，但兼容性不如 86Box/QEMU
- **游戏兼容性不完全**——部分 DOSBox 能跑的游戏在 DOSBox-X 上需调整配置

### 适合场景

- 需要运行真实 DOS 系统的用户
- 需要 3dfx 加速的 DOS 游戏
- 运行中文 DOS 软件（UCDOS、WPS）
- 希望体验接近真机的 DOS 开发环境

## 3. DOSBox Staging

| 项目 | 说明 |
|------|------|
| **官网** | https://dosbox-staging.github.io |
| **类型** | 模拟器（DOSBox 分支，现代化） |
| **开源** | GPL-2.0 |
| **平台** | Windows / macOS / Linux |

### 原理

DOSBox Staging 是 DOSBox 的现代化分支，**专注于游戏场景**，在保持性能的同时修复了大量原版 DOSBox 的 bug。

### 优点

- **性能与原版 DOSBox 相当**——优化良好
- **更好的现代集成**——原生 Wayland 支持、高 DPI 适配
- **改进的音频**——OPL 芯片仿真更精确
- **更多图形选项**——着色器、滤镜、宽屏支持
- **配置可迁移**——可直接使用现有 DOSBox 配置
- **活跃开发**——

### 缺点

- **功能范围小于 DOSBox-X**——不支持 3dfx、Windows 9x 等
- **仍非完整 x86 模拟**

### 适合场景

- DOSBox 用户的直接升级替代
- 追求最佳图像/音频效果的 DOS 游戏

## 4. QEMU

| 项目 | 说明 |
|------|------|
| **官网** | https://www.qemu.org |
| **类型** | 完整 x86 模拟器 + 虚拟化 |
| **开源** | GPL-2.0 |
| **平台** | Windows / macOS / Linux |

### 原理

QEMU 是**完整的 x86 硬件模拟器**，模拟 CPU、芯片组、磁盘控制器、网卡等。可以安装任何 x86 操作系统（MS-DOS、Windows、Linux）。在 Linux 上可配合 KVM 实现硬件加速虚拟化。

### 优点

- **完整 x86 模拟**——可运行 MS-DOS、Windows 全系列、Linux
- **硬件加速选项**——Linux KVM 下性能接近原生
- **网络栈完善**——支持多种虚拟网卡，可搭建复杂网络环境
- **丰富的设备模型**——可配置多种显卡、声卡、网卡
- **快照功能**——支持保存和恢复虚拟机状态
- **脚本化管理**——完全命令行驱动，适合自动化

### 缺点

- **配置复杂**——需要一定的命令行知识
- **无 GUI 管理界面**——需依赖第三方工具（virt-manager）
- **对 DOS 来说太重**——为了运行 DOS 启动整个 PC 模拟，资源浪费
- **声卡兼容有限**——Sound Blaster 模拟不如 DOSBox 精准
- **需自行安装 MS-DOS**——不像 DOSBox 开箱即用

### 适合场景

- 需要完整 PC 环境的开发/测试
- 运行非 DOS 的 x86 操作系统
- 网络实验（如 DOS 联网、Novell NetWare）
- CI/CD 自动化测试

## 5. 86Box

| 项目 | 说明 |
|------|------|
| **官网** | https://86box.net |
| **类型** | 完整 x86 模拟器（周期精确） |
| **开源** | GPL-2.0 |
| **平台** | Windows / Linux |

### 原理

86Box 是 PCem 的活跃分支，专注于**周期精确（cycle-accurate）的 x86 硬件模拟**。它使用真实 BIOS 镜像，模拟从 8088 到 Pentium II 的多种 CPU 和芯片组。

### 优点

- **最高精度的 DOS 模拟**——周期精确，时序与真实硬件一致
- **丰富的硬件配置**——可模拟数十种主板、显卡（3dfx/Voodoo/S3/Matrox）、声卡（Sound Blaster/SB AWE32/GUS/MT-32）、网卡
- **运行操作系统范围广**——从 MS-DOS、Windows 3.x/9x 到 Windows 7
- **支持原始 BIOS**——使用真实机器 BIOS，兼容性极高
- **软驱/光驱外设种类丰富**——支持多种磁盘格式

### 缺点

- **性能开销极大**——周期精确模拟需要大量 CPU 资源
- **运行速度较慢**——在中低端硬件上模拟 Pentium 级别可能卡顿
- **配置复杂**——需要了解硬件知识才能正确配置
- **仅限 Windows/Linux**——不支持 macOS
- **声卡模拟不稳定**——部分声卡驱动有 bug

### 适合场景

- DOS 发烧友和收藏家
- 需要精确硬件兼容性的老软件运行
- 运行对时序敏感的老游戏（如依赖 CPU 速度的早期游戏）
- 研究 DOS/早期 Windows 硬件生态

## 6. VMware Workstation

| 项目 | 说明 |
|------|------|
| **官网** | https://www.vmware.com/products/workstation-pro.html |
| **类型** | 完整 x86 虚拟机（硬件虚拟化） |
| **协议** | 商业软件（有免费 Player 版） |
| **平台** | Windows / Linux |

### 原理

VMware Workstation 是**基于硬件虚拟化的全虚拟化方案**。它通过 CPU 的 VT-x/AMD-V 硬件加速，直接运行 x86 操作系统。对 MS-DOS 来说，VMware 使用真实的硬件虚拟化而非模拟。

### 优点

- **性能极佳**——硬件虚拟化，接近原生速度
- **功能丰富**——快照、克隆、拖拽文件、共享剪贴板
- **网络强大**——NAT、桥接、自定义虚拟网络
- **高版本 MS-DOS 支持**——MS-DOS 6.22 可直接安装在工作站上
- **稳定的商业产品**——完善的技术支持

### 缺点

- **商业软件**——Workstation Pro 收费（Player 免费但功能受限）
- **对 MS-DOS 支持有限**——VMware 主要面向现代 OS，DOS 驱动需手工配置
- **显卡模拟弱**——SVGA 驱动有限，不支持 DOS 下的声卡直通
- **不支持古老硬件特征**——如 EMS/XMS 内存模拟、软盘控制器时序
- **资源占用大**——虚拟机开销比 DOSBox 大得多

### 适合场景

- 在虚拟化环境中运行 MS-DOS 做开发（配合 MASM/Turbo C）
- DOS+Windows 3.x/9x 混合环境
- 需要与宿主机深度交互的场景（拖拽、共享）

## 7. VirtualBox

| 项目 | 说明 |
|------|------|
| **官网** | https://www.virtualbox.org |
| **类型** | 完整 x86 虚拟机 |
| **开源** | GPL-2.0（含闭源扩展包） |
| **平台** | Windows / macOS / Linux |

### 原理

与 VMware 类似，VirtualBox 是基于硬件虚拟化的 x86 虚拟机。通过 VT-x/AMD-V 加速，支持安装 MS-DOS 等操作系统。

### 优点

- **免费开源**——个人和商业使用免费
- **跨平台**——支持 Windows/macOS/Linux
- **功能齐全**——快照、无缝模式、共享文件夹
- **易用的 GUI**——虚拟机创建向导适合新手
- **活跃社区**——资料丰富

### 缺点

- **MS-DOS 兼容性不如 VMware**——部分 DOS 硬件兼容存在问题
- **性能低于 VMware**——I/O 性能较差
- **不支持 DOS 下声卡直通**——Sound Blaster 模拟效果差
- **3D 加速对 DOS 无意义**——面向现代 OS 的功能
- **独占锁机制**——VMX 文件被锁定时难以脚本化操作

### 适合场景

- 免费轻量运行 MS-DOS
- 跨平台 DOS 开发环境
- 教育和学习用途

## 8. js-dos

| 项目 | 说明 |
|------|------|
| **官网** | https://js-dos.com |
| **类型** | 浏览器内 DOS 模拟器 API |
| **开源** | 开源（前端 API） |
| **平台** | 浏览器 / Node.js |

### 原理

js-dos 是 **DOSBox/DOSBox-X 的 WebAssembly 封装**。它将 DOSBox 编译为 WASM，在浏览器中运行。提供简洁的 JavaScript API，支持一键挂载 DOS 程序包。

### 优点

- **无需安装**——浏览器打开即可运行 DOS
- **易于集成**——几行 JS 代码即可嵌入网页
- **支持 3dfx 渲染**——通过 WebGL 后端实现（唯一浏览器方案）
- **IPX 网络**——浏览器中实现 DOS 多人在线
- **Windows 9x 支持**——通过 DOSBox-X WASM 后端
- **移动端支持**——触屏适配
- **大磁盘流式加载**——Sockdrive V2 技术

### 缺点

- **性能受浏览器限制**——WASM 性能低于原生
- **文件系统隔离**——无法直接访问宿主机文件
- **需要网络加载**——程序包需下载到浏览器
- **依赖浏览器兼容性**——部分特性需要 Chrome 最新版
- **复杂度受限于 DOSBox**——所有 DOSBox 的局限同样存在
- **重度游戏性能不足**——20 年前的 3D 游戏可能卡顿

### 适合场景

- 在线 DOS 游戏平台（如 DOS.Zone）
- 网页演示和老软件存档
- 嵌入式文档中的交互式演示
- 快速分享 DOS 程序给他人

## 9. v86

| 项目 | 说明 |
|------|------|
| **官网** | https://github.com/copy/v86 |
| **类型** | 浏览器内完整 x86 模拟器 |
| **开源** | BSD-2-Clause |
| **平台** | 浏览器 |

### 原理

v86 是一个**完整的 x86 模拟器**，在浏览器中使用 JavaScript 模拟 x86 CPU，通过 **x86-to-WASM JIT** 编译器实现性能提升。与 js-dos 不同，v86 模拟完整硬件，可启动任何 x86 操作系统。

### 优点

- **完整 x86 模拟**——可运行 MS-DOS、FreeDOS、Windows 95/98/2000、Linux
- **无需安装**——浏览器即可运行
- **x86-to-WASM JIT**——动态编译 x86 指令为 WebAssembly，性能较好
- **支持网络**——虚拟 NIC，可通过 WebSocket 连接网络
- **多种 OS 配置**——官方提供多种预构建镜像
- **开源且文档完善**

### 缺点

- **性能远低于原生**——通常只有真机 20-40% 的速度
- **无硬件加速**——完全靠软件模拟，对 CPU 要求高
- **浏览器限制**——无法直接访问 USB、串口等外设
- **启动慢**——启动操作系统需要 10-30 秒
- **不支持 64 位**——最高 32 位 x86
- **声卡支持有限**——部分音频不工作
- **文件持久化复杂**——需要 9P 文件系统或 IndexedDB

### 适合场景

- 在线演示老旧操作系统（如 copy.sh/v86）
- 教育用途（展示操作系统启动过程）
- 快速测试不同 OS 发行版
- 不需要高性能的复古环境展示

## 如何选择

### 我只是想玩 DOS 游戏
→ **DOSBox** / **DOSBox Staging**（最简单，兼容性最好）

### 我需要运行中文 DOS 软件（UCDOS、WPS、CCED）
→ **DOSBox-X**（对中文环境支持最好）或 **86Box**（如果追求精度）

### 我需要在 DOS 下做汇编/C 开发
→ **DOSBox-X**（可挂载真实 MS-DOS + 工具链）或 **VMware**（与宿主机文件交互方便）

### 我追求最真实的 DOS 体验
→ **86Box**（周期精确，时序与真机一致）

### 我需要将 DOS 程序分享给他人在线体验
→ **js-dos**（集成最简单，开箱即用）

### 我需要在浏览器中运行完整的 x86 操作系统
→ **v86**（完整的 x86 模拟，可启动 Linux/Windows）

### 我需要 DOS+Windows 9x 混合环境
→ **QEMU**（免费、功能完整）或 **VMware**（性能更佳）
